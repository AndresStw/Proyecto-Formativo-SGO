## 📖 Documentación y Recursos

### Requisitos Funcionales (RF)
Los requisitos funcionales definen QÚES el sistema debe hacer:
- Gestión de usuarios
- Control de acceso
- Procesamiento de datos
- Generación de reportes

### Requisitos No Funcionales (RNF)
Los requisitos no funcionales especifican CÓMO el sistema debe hacerlo:
- Rendimiento y velocidad
- Seguridad
- Confiabilidad
- Escalabilidad

### Análisis de Procesos (BPMN)
Los diagramas BPMN ilustran los flujos de negocio:
- Procesos principales
- Interacciones entre actores
- Decisiones y puntos de control
