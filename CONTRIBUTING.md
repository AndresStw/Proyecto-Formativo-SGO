# Contributing Guide — Sabor Caleño Backend

## Ground rules

1. **Never** commit directly to `main` or `backen`.
2. **Never** upload `.env` to the repository.
3. **Never** modify Supabase SQL without approval via PR.
4. **Always** work on your own branch.
5. **Always** open a PR before merging.

---

## Workflow

### 1. Update your local branch before starting

```powershell
git checkout backen
git pull origin backen
```
